# یادداشت ورود مجموعه Skillها به مخزن

این مخزن شامل 60 فایل Skill مستقل است که بر اساس کاتالوگ مادر و قرارداد مشترک پروژه در ساختار مخزن ثبت شده‌اند. نسخه مخزن، ساختار یکپارچه‌تری برای front matter، قرارداد خروجی، کنترل کیفیت، امنیت و آزمون پذیرش دارد.

این فایل‌ها باید به‌عنوان نسخه مشخصات مخزن (repository-native specification baseline) در نظر گرفته شوند؛ نه ادعای وجود کد اجرایی یا اتصال زنده. پیش از هر توسعه اجرایی، جزئیات دامنه و معیارهای خاص هر Skill باید با نیازهای واقعی و منابع رسمی تطبیق داده شود.

وضعیت همه موارد: SPECIFICATION.
