# امنیت و حاکمیت

سامانه تصمیم‌یار است؛ تحلیل یا پیشنهاد به‌معنای اختیار معامله نیست. ارسال، اصلاح یا لغو سفارش واقعی نیازمند مجوز صریح، احراز هویت قوی، نمایش جزئیات سفارش، سقف ریسک و audit است.

## کنترل پیش از اتصال کارگزاری
- مستندات رسمی API و مجوز استفاده؛
- مدیریت امن secret و rotation؛
- idempotency و جلوگیری از سفارش تکراری؛
- تطبیق وضعیت سفارش؛
- kill switch و محدودیت مبلغ/حجم؛
- تأیید انسانی با نمایش نماد، سمت، قیمت، حجم و حساب؛
- sandbox/paper trading و تست خطا؛
- ثبت درخواست، پاسخ و تأیید.

## امنیت داده
حداقل‌سازی داده، رمزنگاری انتقال و ذخیره‌سازی، کنترل دسترسی نقش‌محور، عدم ثبت token/password در log، backup رمزنگاری‌شده و آزمون بازیابی الزامی است. هر پیشنهاد باید شواهد، فرضیات، نسخه مدل، ریسک‌ها و دلیل override را ثبت کند.
